# Агро-помощник 4.7

Приложение для фермеров и агрономов Казахстана: дневник полей, севооборот и прибыль на гектар, учёт сорняков и вредителей с порогом хозяйства, погода и окна для опрыскивания, проверки по нормативам РК. Работает в браузере телефона и без интернета, данные хранятся на устройстве.

Открыть: https://yoniiii-crypto.github.io/agro-pomoshnik/

Для жюри: https://yoniiii-crypto.github.io/agro-pomoshnik/?demo=1 — сразу открывает пример хозяйства (синтетические данные за 4 сезона) и короткий тур по главным экранам.

Автор: Саутбаев Эльсид Тимурович, yonirem9@gmail.com

## Что умеет

| Раздел | Что делает |
|---|---|
| Сводка | Погода на неделю по области, заморозки и окна для опрыскивания, «Требует внимания», задачи, прибыль по полям, быстрые действия «В поле» |
| Дневник | Запись операции за минуту, фото, срок ожидания после химобработки, загрузка и выгрузка Excel (CSV), отчёт для печати, помощь с формой ФУ-4 |
| Поля | История культур и урожайности, совет, что сеять дальше, безубыточная урожайность, паспорт поля, история учётов на площадках |
| Защита растений | Учёт сорняков и вредителей на площадках с порогом хозяйства, оповещения о саранче по областям |
| Что с растением | Определитель болезней, вредителей и нехватки питания по признакам для зерновых, подсолнечника, рапса и картофеля |
| ИИ-агроном | Запись в дневник обычной фразой или голосом, определение проблемы по фото растения с учётом истории поля, вопросы ИИ о конкретном поле, оценка ответов агрономом. На сайте работает через сервер-посредник (см. ниже), в версии на claude.ai — через Claude |
| Калькуляторы | Выгода для хозяйства (окупаемость), удобрения (из д.в. в килограммы), площадь поля по GPS, норма высева, бак опрыскивателя, зачётный вес зерна |
| Проверка хозяйства | Монокультура, ранний возврат культуры, учёт выше порога без обработки, уборка раньше срока ожидания и другие правила со ссылкой на источник |
| Ещё | Риск урожая по зонам, пастбища (приказ № 394), корма на зиму, план работ с календарём, несколько хозяйств, нормы агронома, казахский язык, резервная копия |

Проверенных порогов вредоносности и доз препаратов в приложении нет: пороги вписывает хозяйство, препараты берутся только из Государственного реестра пестицидов РК.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | само приложение (его можно открыть и просто файлом) |
| `sw.js` | офлайн-режим: сохраняет приложение на телефоне после первого открытия |
| `manifest.webmanifest`, `icon-*.png`, `icon.svg` | установка на главный экран с иконкой |
| `server/ai-proxy-worker.js` | сервер-посредник для ИИ Google Gemini (Cloudflare Worker), ключ хранится только на нём |

## ИИ на сайте: сервер-посредник

Ключ Gemini нельзя класть в код сайта: код публичный, и ключ сразу утечёт. Поэтому сайт отправляет запросы ИИ на маленький бесплатный сервер (Cloudflare Worker), а тот добавляет ключ и пересылает запрос в Google. Сервер принимает запросы только со страниц сайта.

1. Получите ключ на aistudio.google.com: «Get API key» → «Create API key». Оплату (billing) не подключайте.
2. Зайдите на dash.cloudflare.com (бесплатная регистрация) → Workers & Pages → Create → Worker → Deploy.
3. Нажмите «Edit code», замените код содержимым `server/ai-proxy-worker.js` и нажмите Deploy.
4. Settings → Variables and Secrets → Add: тип Secret, имя `GEMINI_KEY`, значение — ваш ключ. Сохраните.
5. Адрес сервера вида `https://<имя>.<ваш-поддомен>.workers.dev` впишите в `index.html` в строку `var AI_PROXY=''`.

Если сайт переехал на другой адрес, добавьте его в список `ALLOWED_ORIGINS` в коде сервера.

## Как выложить (бесплатно)

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки.
2. В репозитории откройте Settings → Pages, выберите ветку `main` и папку `/ (root)`.
3. Через минуту приложение будет доступно по адресу вида `https://<логин>.github.io/<репозиторий>/`.

Подойдёт любой хостинг статических файлов с HTTPS (Netlify, Cloudflare Pages и другие). Без HTTPS офлайн-режим не включится.

## Как установить на телефон

- Android (Chrome): откройте адрес, меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- iPhone (Safari): кнопка «Поделиться» → «На экран Домой».

После первого открытия приложение работает без связи. Интернет нужен для прогноза погоды, ссылок на документы и голосовой диктовки.

## Обновление

Замените `index.html` на сайте. Если меняли `sw.js`, поднимите в нём номер версии в `CACHE`, чтобы телефоны забрали новую копию.

## Данные

Записи хранятся только в браузере телефона. Общей базы и входа пока нет: делайте резервную копию на вкладке «Ещё» → «Резервная копия и офлайн» → «Сохранить копию». Приложение напомнит, если копию давно не сохраняли.
