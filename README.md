# Alqap 8.1

Alqap (каз. «алқап» — поле, угодье) — ИИ-агроном и учёт хозяйства в телефоне фермера. До версии 8.0 приложение называлось «Агро-помощник»; адрес сайта и формат файлов хозяйства не изменились.

**1 место на AI Startup Building Hackathon 2026** (Агротехнопарк Seifullin University, Астана, 13 ноября 2026, трек Smart Agro).

Приложение для фермеров и агрономов Казахстана: дневник полей, севооборот и прибыль на гектар, учёт сорняков и вредителей с порогом хозяйства, погода и окна для опрыскивания, проверки по нормативам РК. Работает в браузере телефона и без интернета, данные хранятся на устройстве. Это не только приложение, но и платформа: фермер, агроном и консультант работают в одном общем хозяйстве со своих телефонов, консультант видит все свои хозяйства на одном экране, а банк или страховая смотрят записи по коду «только просмотр» и получают профиль хозяйства с урожайностью за 5 лет.

Открыть: https://yoniiii-crypto.github.io/agro-pomoshnik/

Для жюри: https://yoniiii-crypto.github.io/agro-pomoshnik/?demo=1 — сразу открывает пример хозяйства (синтетические данные за 4 сезона) и короткий тур по главным экранам. На казахском: https://yoniiii-crypto.github.io/agro-pomoshnik/?demo=1&lang=kk (параметр `lang=kk` или `lang=ru` включает язык и запоминает его). Проверить ИИ без больного растения: «Что с растением» → «Пример фото» → «Определить»; ещё раз — другая болезнь. На «Сводке» — «План на неделю» от ИИ.

## ИИ на сайте: сервер-посредник

Ключ Gemini нельзя класть в код сайта: код публичный, и ключ сразу утечёт. Поэтому сайт отправляет запросы ИИ на маленький бесплатный сервер (Cloudflare Worker), а тот добавляет ключ и пересылает запрос в Google. Сервер принимает запросы только со страниц сайта.

1. Получите ключ на aistudio.google.com: «Get API key» → «Create API key». Оплату (billing) не подключайте.
2. Зайдите на dash.cloudflare.com (бесплатная регистрация) → Workers & Pages → Create → Worker → Deploy.
3. Нажмите «Edit code», замените код содержимым `server/ai-proxy-worker.js` и нажмите Deploy.
4. Settings → Variables and Secrets → Add: тип Secret, имя `GEMINI_KEY`, значение — ваш ключ. Сохраните.
5. Адрес сервера вида `https://<имя>.<ваш-поддомен>.workers.dev` впишите в `index.html` в строку `var AI_PROXY=''`.

Проверить подключение можно с телефона: «Ещё» → «Ваши данные» → «Проверить ИИ». Там видно, отвечает ли ИИ и какая модель, а при ошибке — текст ошибки сервера (например, `GEMINI_KEY is not set on the server`, если не добавлен секрет).

Если сайт переехал на другой адрес, добавьте его в список `ALLOWED_ORIGINS` в коде сервера.

Бесплатный тариф Gemini подходит для показа на синтетических данных. По [условиям Gemini API](https://ai.google.dev/terms) на бесплатном тарифе Google может использовать запросы для улучшения своих сервисов, и их могут читать проверяющие. Для работы с реальными хозяйствами подключите к проекту оплату (billing): на платном тарифе запросы для этого не используются.

## Общая база: одно хозяйство на нескольких телефонах

«Ещё» → «Хозяйства» → «Сделать это хозяйство общим». Приложение покажет два кода:

- **код для совместной работы** — читать и менять записи (фермер, агроном, консультант);
- **код «только просмотр»** — только смотреть записи (банк, страховая, наблюдатель). Вносить записи с ним нельзя, и сервер такую запись не примет.

Код можно отправить ссылкой: тот, кто её откроет, подтвердит подключение, и хозяйство появится у него на телефоне. Правки отправляются через пару секунд после записи, а чужие приходят сами. Без интернета работа идёт как обычно: когда связь вернётся, правки с разных телефонов сведутся, и ничего не затрётся. Если двое изменили одну и ту же запись, остаётся более поздняя правка.

Команда. В том же разделе каждый пишет своё имя («Ваше имя в записях», например «агроном Ерлан»). Новые записи и задачи с этого телефона подписываются этим именем. Если запись поправили, у неё видно, кто и когда. В плане работ у задачи есть поле «Кому»: тот, кому её поставили, получит сообщение «Новая задача для вас» и увидит пометку «вам», а автор задачи — сообщение, когда её выполнят. На «Сводке» общего хозяйства есть карточка «Команда» с последними записями коллег.

Обсуждение. У каждой записи общего хозяйства есть кнопка «Обсудить»: агроном пишет совет прямо к записи фермера («похоже на септориоз, пришлите фото»), фермер отвечает. Кнопка «Спросить ИИ» зовёт в обсуждение ИИ-агронома: он видит запись, историю поля, всё обсуждение и фото к записи, а его ответ становится комментарием для всей команды. О новых комментариях приходит сообщение, последние комментарии коллег видны на «Сводке». Наблюдатель с кодом просмотра обсуждение читает, но писать не может.

Фото. Фото к записям тоже становятся общими: телефон отправляет свои новые фото после синхронизации записей (по три за раз), а чужие загружает, когда их открывают, и понемногу в фоне. Каждое фото шифруется на телефоне отдельно. На сервере до 300 фото на хозяйство; если место кончилось, новые фото остаются на телефоне, где сняты, и приложение об этом пишет. Фото удалённых записей сервер хранит ещё сутки, потом телефон с полным доступом их убирает.

Как устроена защита. Из кода на телефоне получаются номер хозяйства, токен доступа и ключ шифрования. На сервер уходят только номер, токен и уже зашифрованные записи (AES-GCM); ключ остаётся на телефоне, поэтому сервер прочитать записи не может. Сервер хранит не сами токены, а их хеши. Код «только просмотр» получается из полного кода, а обратно — нет.

Как включить на своём сервере (бесплатно, тот же воркер, что для ИИ):

1. dash.cloudflare.com → Storage & databases → D1 SQL database → Create, имя `agro`.
2. Workers & Pages → ваш воркер → Edit code → замените код содержимым `server/ai-proxy-worker.js` → Deploy.
3. Settings → Bindings → Add → D1 database: Variable name `AGRO_DB`, база `agro` → Deploy.

Таблицы (хозяйства и фото) сервер создаст сам. Бесплатная база D1 вмещает до 500 МБ: сервер не даёт фото занять больше 300 МБ, остальное остаётся записям. Пока привязки нет или на сервере старый код, раздел «Общая база» в приложении просто не показывается, а ИИ работает как раньше.

Совместимость. Если более новая версия приложения добавит свой вид данных, старая версия его не поймёт, но при слиянии сохранит и отправит обратно без изменений, так что данные не потеряются, пока кто-то в команде не обновился.

Проверки: `node tests/sync-server.test.mjs` (сервер на SQLite), `node tests/sync-merge.test.mjs` (сведение правок, в том числе случайные правки на трёх телефонах со сбитыми часами), `NODE_PATH=$(npm root -g) node tests/sync-e2e.test.js` (несколько телефонов в браузере, нужен Playwright). Нужен Node 22.5 или новее.

Проверки экранов (нужен Playwright, приложение открывается с локального сервера, ИИ и погода подменены):

```bash
for f in tests/ui-*.test.js; do NODE_PATH=$(npm root -g) node "$f" | tail -1; done
```

`ui-team` — команда и автор записи, `ui-discussion-ai` — обсуждение и «Спросить ИИ», `ui-tasks` — правки, окна опрыскивания, задачи консультанта, `ui-diary` и `ui-diary-paging` — категории, выгрузка и большой дневник, `ui-sections` — разделы экранов и тур, `ui-seeds` — семена и удобрения на сезон, `ui-stock` — склад и продажи, `ui-bank` — профиль для банка, `ui-costs` — структура затрат, `ui-copy` — запись на другие поля, `ui-bounds` — граница поля, `ui-lang-link` — ссылка с языком и казахские названия на «Сводке», `ui-agro` — агрономы онлайн.

## Агрономы онлайн: настройка сервера

Работает на той же базе `AGRO_DB`, что и общая база (таблицы `agros` и `orders` сервер создаст сам).

1. Обновите код воркера содержимым `server/ai-proxy-worker.js` → Deploy.
2. Settings → Variables and Secrets → Add → тип Secret, имя `AGRO_ADMIN`, значение — длинный пароль администратора (не короче 20 символов, никому не показывать) → Deploy.
3. По желанию: переменная `AGRO_FEE_PCT` — комиссия Alqap в процентах (по умолчанию 10).

Админка открывается по ссылке с `?admin=1`: https://yoniiii-crypto.github.io/agro-pomoshnik/?admin=1 → «Ещё» → «Агрономы онлайн» → «Для администратора Alqap» → ввести пароль. Там: проверка анкет, «Оплата получена» (после того как фермер оплатил счёт), «Выплачено агроному» и итоги — сколько оплачено, комиссия Alqap и сколько выплатить агрономам.

Оплата пока ручная: администратор выставляет фермеру счёт (например, через Kaspi) и отмечает оплату. Чтобы принимать деньги от фермеров и выплачивать агрономам официально, нужны ИП или ТОО, договор с платёжной системой, оферта для фермеров и договоры с агрономами; после этого сервер можно подключить к платёжной системе вместо ручной отметки.

Проверки: `node tests/agro-server.test.mjs` (сервер на SQLite) и `NODE_PATH=$(npm root -g) node tests/ui-agro.test.js` (агроном, фермер и администратор в трёх браузерах).

## Как выложить (бесплатно)

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки.
2. В репозитории откройте Settings → Pages, выберите ветку `main` и папку `/ (root)`.
3. Через минуту приложение будет доступно по адресу вида `https://<логин>.github.io/<репозиторий>/`.

Подойдёт любой хостинг статических файлов с HTTPS (Netlify, Cloudflare Pages и другие). Без HTTPS офлайн-режим не включится.

## Как установить на телефон

- Android (Chrome): откройте адрес, меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- iPhone (Safari): кнопка «Поделиться» → «На экран Домой».

После первого открытия приложение работает без связи. Интернет нужен для прогноза погоды, ссылок на документы и голосовой диктовки.

## Обновление

Замените `index.html` на сайте. Если меняли `sw.js`, поднимите в нём номер версии в `CACHE`, чтобы телефоны забрали новую копию.

## Данные

Записи хранятся в браузере телефона. У общего хозяйства, кроме того, есть зашифрованная копия на сервере (см. «Общая база»). Всё равно делайте резервную копию на вкладке «Ещё» → «Резервная копия и офлайн» → «Сохранить копию». Приложение напомнит, если копию давно не сохраняли.
